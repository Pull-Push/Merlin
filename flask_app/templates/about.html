About Merlin

Merlin is a real-time chat app with a built-in cipher. Everyone in a room agrees on a numeric shift and three code words. Those four values deterministically scramble the character set into four substitution alphabets, and each message is passed through all four in sequence.

Click any message in the chat to decode it with the keys you've entered. Wrong keys produce gibberish.

Merlin is a learning project. Please don't use it to protect anything that really matters.
